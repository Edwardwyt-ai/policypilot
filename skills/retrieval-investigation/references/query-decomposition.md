# Query Decomposition

Anchor every query to one active POLICY InformationNeed, its entity, aspect, policy scope, and preserved hard constraints. Split only when independent conditions require different evidence, such as eligibility versus timing.

Do not split a simple Need for superficial recall gains. Each subquery must have a distinct coverage criterion and must remain traceable to the original Need.

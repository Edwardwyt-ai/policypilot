# Minimum Questioning

- Is the ambiguity actually blocking?
- Can an existing Fact resolve it?
- Is TOOL or POLICY the authoritative source?
- Which single answer most reduces the remaining action space?
- Is the requested detail necessary and proportionate?
- Has the same question already been resolved?

Ask no more than the current decision needs.

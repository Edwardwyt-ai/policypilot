# Candidate Evaluation

1. **Eligibility:** eliminate evidenced hard-constraint violations. Keep unknown critical cases unresolved rather than treating them as passes.
2. **Preference fit:** compare how eligible candidates satisfy soft preferences.
3. **Optimization:** rank remaining candidates on the stated objective using comparable evidence.
4. **Trade-off:** explain only trade-offs the user permitted or that are necessary to distinguish finalists.

If evidence is not candidate-specific or not comparable in scope, return to the corresponding Need instead of manufacturing a ranking.

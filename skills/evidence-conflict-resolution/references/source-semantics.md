# Source Semantics

- **USER:** authoritative for current intent, choices, and self-reported preferences; not authoritative for live account state.
- **TOOL:** authoritative observation of live business state within its entity, aspect, and observation time.
- **POLICY:** authoritative for rules within document scope and effective context; not proof that a user satisfies a condition.
- **MEMORY:** non-authoritative historical assistance. Current explicit user expression supersedes a remembered preference.

Authority is claim-specific, not a universal source ranking.

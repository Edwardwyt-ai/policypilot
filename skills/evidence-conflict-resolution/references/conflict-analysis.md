# Conflict Analysis

Before declaring conflict, normalize each claim as entity, aspect, value, source, observation time, and scope. Different entities, fields, time slices, or policy versions may be compatible rather than contradictory.

Classify a real mismatch as stale data, authority mismatch, semantic mismatch, identity mismatch, or policy-scope mismatch. Then create only the USER, TOOL, or POLICY Need capable of resolving the material difference.

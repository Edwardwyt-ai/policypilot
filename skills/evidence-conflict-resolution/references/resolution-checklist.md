# Resolution Checklist

- Same entity, aspect, time, and scope?
- Which source is authoritative for this exact claim?
- Has a mutation invalidated the observation?
- Does current explicit intent supersede Memory?
- Does the conflict affect a critical prerequisite or recommendation?
- Which single authoritative Need resolves it?
- If unresolved, is uncertainty stated and mutation withheld?
